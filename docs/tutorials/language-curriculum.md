# Language-building learning path

Follow the [start-to-finish course](./course/) to grow a TypeScript-like language
from grammar through analysis and host backends. It supplies complete file updates,
runnable commands, and explicit transitions to the maintained Mini TypeScript,
structural-data, and backend checkpoints.

The [numbered example catalog](https://github.com/gweiermann/your-language/tree/main/examples)
remains available for focused exploration. Existing friendly and numbered Cargo
entrypoints work together; each project uses `yl.json` and `.txt` programs.

Use the [concept guides](/guide/syntax-and-values) for individual ideas and the
[standard-library reference](/reference/standard-library) for exact module exports.
The course separates general mechanisms from explicit opinionated policies and
makes experimental subset limits visible.
