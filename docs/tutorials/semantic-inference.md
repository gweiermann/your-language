# Scopes and type inference

The [std/types tutorial](/tutorials/std-types) explains type evidence, restrictions, language-owned symbols, identity-keyed function signatures, and isolated generic calls using the current Mini TypeScript example.

Start with [authored lexical scopes](/tutorials/declarative-scopes) for declaration ownership and shadowing, then follow the type tutorial to connect reference identities to type queries. Both standard libraries are YL modules compiled into the artifact; consumers do not need a native variable or type solver.
